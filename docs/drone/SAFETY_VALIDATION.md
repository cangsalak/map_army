## 1. ลำดับชั้นการตรวจสอบความปลอดภัย (Multi-Layer Safety Verification)

ก่อนที่ภารกิจจะสามารถบันทึก ส่งออก หรือส่งคำสั่งอัปโหลดไปยังอากาศยานได้ ระบบจะทำการตรวจสอบความปลอดภัยผ่าน 6 ด่านสำคัญ (6 Safety Gates):

```
[แผนการบินจาก Mission Core]
          │
          ▼
Gate 1: Data Integrity ───► ตรวจสอบชื่อ, พิกัดละติจูด/ลองจิจูด, โครงสร้างข้อมูล GeoJSON
          │
          ▼
Gate 2: Platform Limits ──► ตรวจสอบขีดจำกัดจำนวน Waypoint, ระยะทางบินสูงสุด, รูปแบบภารกิจ
          │
          ▼
Gate 3: Airspace & Rules ─► ตรวจสอบเพดานบินตามกฎหมาย CAAT (<= 120m AGL), เขตห้ามบิน (NFZ)
          │
          ▼
Gate 4: Terrain Elevation ► ตรวจสอบระยะความสูงปลอดภัยจากพื้นผิว 3D Terrain นิคมฯ มาบตาพุด
          │
          ▼
Gate 5: Failsafe Protocols► ตรวจสอบจุด Home Point, ความสูง RTH, พฤติกรรมเมื่อสัญญาณขาดหาย
          │
          ▼
Gate 6: Human Authorization► ผู้ควบคุมหน้างานตรวจสอบและลงนามอนุมัติ (Human-in-the-Loop)
          │
          ▼
[อนุมัติการบิน / ปลดล็อกปุ่มเริ่มบิน]
```

## 2. เกณฑ์การจำแนกสถานะการตรวจสอบ (Validation Status Matrix)

| สถานะ (Status) | สัญลักษณ์ UI | ความหมายเชิงปฏิบัติการ | ผลต่อระบบ (System Action) |
| :---: | :---: | :--- | :--- |
| **`PASS`** | 🟢 สีเขียว | ผ่านเกณฑ์ความปลอดภัยทุกข้อ ไม่มีข้อผิดพลาด | อนุญาตให้บันทึก ส่งออก และอัปโหลดได้สมบูรณ์ |
| **`WARNING`** | 🟡 สีส้ม | ผ่านเกณฑ์ขั้นต่ำ แต่มีข้อควรระวัง (เช่น บินเกิน 90m หรือใช้โหมด AGL) | อนุญาตให้ดำเนินการได้ แต่ต้องแสดงคำเตือนสีส้ม |
| **`BLOCKED`** | 🔴 สีแดง | มีข้อผิดพลาดร้ายแรง (เช่น ไม่มีจุด Home, จุดบินออกนอกประเทศ, เกิน 500m) | **ล็อกปุ่ม Upload และ Export ทุกฟอร์แมตทันที** |
| **`NOT_VERIFIED`**| ⚪ สีเทา | ข้อมูลยังไม่เพียงพอสำหรับการประเมิน (เช่น ยังไม่ได้วาดพื้นที่) | ไม่อนุญาตให้ดำเนินการจนกว่าจะกรอกข้อมูลครบ |

## 4. กฎการตรวจสอบความปลอดภัยเฉพาะจุด (Specific Inspection Rules)

1. **การตรวจสอบสิ่งกีดขวางและแนวสายไฟ (Obstacle Clearance)**:
   - ห้ามใช้ความสูงต่ำกว่า 40 เมตรในพื้นที่นิคมอุตสาหกรรมมาบตาพุด เนื่องจากมีปล่องระบายควัน หอเผาก๊าซ (Flare Stack) และเสาส่งไฟฟ้าแรงสูง
2. **การป้องกันการชนพื้นดิน (Ground Collision Prevention)**:
   - เมื่อเลือกโหมด `relative_to_home` ระบบจะเปรียบเทียบค่าความสูงของพื้นผิวดินตลอดแนวบิน หากพบว่าจุดใดมีความสูงห่างจากพื้นดินน้อยกว่า 20 เมตร ระบบจะแจ้งเตือนระดับ `error` และบล็อกภารกิจทันที
3. **การตัดการทำงานฉุกเฉิน (Emergency Abort)**:
   - ผู้ควบคุมระบบต้องสามารถกดปุ่ม **EMERGENCY PAUSE** หรือ **RTH** ได้ตลอดเวลาในขณะที่โดรนกำลังปฏิบัติการบิน
