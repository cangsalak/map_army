# 05-login-and-users.md — การเข้าสู่ระบบและจัดการผู้ใช้

## วัตถุประสงค์
เอกสารฉบับนี้อธิบายกระบวนการยืนยันตัวตน (Authentication) การบริหารจัดการสิทธิ์ตามบทบาท (Role-Based Access Control - RBAC) บัญชีผู้ใช้งานเริ่มต้นของระบบ ตลอดจนขั้นตอนการเข้าถึงหน้าแดชบอร์ดบริหารจัดการผู้ใช้งาน (`/admin`)

---

## สิ่งที่ต้องเตรียม
- เว็บบราวเซอร์ที่เข้าถึง URL ของระบบ GeoMonitor 3D ได้ เช่น `http://localhost:3000/login` หรือ `http://localhost/login`
- บัญชีผู้ใช้งานที่ได้รับการลงทะเบียนในฐานข้อมูล

---

## บัญชีผู้ใช้งานเริ่มต้นของระบบ (Default Pre-Seeded Accounts)

เมื่อรันคำสั่ง `npm run db:seed` ระบบจะสร้างบัญชีตัวอย่างเริ่มต้น 4 บัญชีที่ครอบคลุมทุกบทบาทหน้าที่:

| บัญชีอีเมล (Email) | บทบาทในระบบ (Role) | ตำแหน่งหน้าที่และการเข้าถึง |
|---|---|---|
| `admin@geomonitor.local` | `admin` | **ผู้ดูแลระบบสูงสุด (Chief Administrator)**<br>เข้าถึงได้ทุกเมนู จัดการผู้ใช้ ดูสถานะเซิร์ฟเวอร์ และล้างข้อมูลปฏิบัติการ |
| `pm@geomonitor.local` | `project_manager` | **ผู้จัดการโครงการ (Senior Project Director)**<br>สร้างโครงการ สร้างพื้นที่ดูแล และออกรายงานระดับผู้บริหาร |
| `analyst@geomonitor.local` | `analyst` | **นักวิเคราะห์ภาพถ่าย (Lead Photogrammetry Analyst)**<br>นำเข้าภาพถ่ายโดรน สั่งรันการตรวจจับความเปลี่ยนแปลง และรับรองผล |
| `viewer@geomonitor.local` | `viewer` | **ผู้ตรวจดูข้อมูล (Environmental Inspector)**<br>ดูแผนที่ 3 มิติ และตรวจสถิติการเปลี่ยนแปลง (สิทธิ์อ่านอย่างเดียว) |

> [!NOTE]
> รหัสผ่านเริ่มต้นสำหรับทุกบัญชีในการทดสอบครั้งแรกคือ: `Password123!`

> [!CAUTION]
> ในการนำไปใช้งานจริงบนระบบ Production ผู้ดูแลระบบต้องเปลี่ยนรหัสผ่านเริ่มต้นทันที หรือสร้างบัญชีผู้ใช้งานจริงของหน่วยงานผ่านฐานข้อมูลหรือ API

---

## ขั้นตอนการเข้าสู่ระบบผ่านหน้าเว็บ (Web UI Login Steps)

1. เปิดเว็บบราวเซอร์ไปที่หน้าล็อกอิน: `http://localhost:3000/login`
2. กรอก **อีเมล** และ **รหัสผ่าน** ในช่องข้อมูล
3. คลิกปุ่ม **"เข้าสู่ระบบ (Sign In)"**
4. ระบบจะทำการตรวจสอบความถูกต้องผ่าน API `POST /api/v1/auth/login` และสร้าง JWT Access Token พร้อม Refresh Token
5. เมื่อยืนยันตัวตนสำเร็จ ระบบจะนำท่านเข้าสู่ **ศูนย์บัญชาการแผนที่ 3 มิติ (3D Command Center)** ทันที
6. ชื่อผู้ใช้งานและบทบาทจะแสดงที่มุมขวาบนของหน้าจอ (Navbar Profile Menu)

---

## การสลับสิทธิ์การทดสอบอย่างรวดเร็ว (Quick Demo Switcher)
บนหน้าจอ `/login` ระบบมีแถบปุ่มด่วน **"ทดสอบเข้าใช้งานด่วน (Quick Demo Sign-In)"** 4 ปุ่ม:
- คลิกปุ่ม **"ผู้ดูแลระบบ (Admin)"** เพื่อทดสอบฟังก์ชันด้านระบบและความปลอดภัย
- คลิกปุ่ม **"ผู้จัดการ (PM)"** เพื่อทดสอบการสร้างโครงการและกำหนดพื้นที่
- คลิกปุ่ม **"นักวิเคราะห์ (Analyst)"** เพื่อทดสอบการคำนวณปริมาตรดินและตรวจรับรองผล
- คลิกปุ่ม **"ผู้ตรวจดู (Viewer)"** เพื่อทดสอบข้อจำกัดสิทธิ์อ่านอย่างเดียว

---

## การตรวจสอบรายชื่อผู้ใช้งานในระบบ (`/admin`)

สำหรับผู้ใช้งานที่มีสิทธิ์ `admin`:
1. คลิกเมนู **"ผู้ดูแลระบบ"** บนแถบ Navbar ด้านบน หรือเข้าไปที่ `http://localhost:3000/admin`
2. แท็บแรก **"ผู้ใช้งานและสิทธิ์ (Users & Roles)"** จะแสดงตารางรายชื่อบัญชีทั้งหมดที่ดึงมาจากฐานข้อมูลจริงผ่าน API `GET /api/v1/users`
3. ตารางจะแสดง:
   - **ชื่อ-นามสกุล** และรูปแทนตัว
   - **อีเมล** ของผู้ใช้งาน
   - **บทบาท (Role)** พร้อมสีจำแนก (Admin: สีแดง, PM: สีเหลืองทอง, Analyst: สีฟ้าไซแอน, Viewer: สีเทา)
   - **สังกัดหน่วยงาน (Organization)**
   - **เวลาลงทะเบียน / เข้าสู่ระบบล่าสุด**
   - **สถานะบัญชี** (เปิดใช้งาน / ระงับ)

## ตารางเมทริกซ์สิทธิ์การเข้าถึงฟังก์ชัน (RBAC Permission Matrix)

## การออกจากระบบ (Sign Out)
1. คลิกที่รูปโปรไฟล์ที่มุมขวาบนของหน้าจอ
2. คลิกปุ่ม **"ออกจากระบบ (Sign Out)"**
3. ระบบจะเรียก API `POST /api/v1/auth/logout` เพื่อล้างคุกกี้โทเค็น และบันทึกเหตุการณ์ลงใน Audit Log

---

## ข้อผิดพลาดที่พบบ่อยและวิธีแก้ไข

### ข้อผิดพลาด: `INVALID_CREDENTIALS` (อีเมลหรือรหัสผ่านไม่ถูกต้อง)
- **สาเหตุ**: กรอกรหัสผ่านผิด หรือฐานข้อมูลยังไม่มีการ Seed ข้อมูล
- **วิธีแก้ไข**: รันคำสั่ง `npm run db:seed --workspace=@geomonitor/api` เพื่อสร้างบัญชีเริ่มต้น

### ข้อผิดพลาด: `ACCOUNT_DISABLED` (บัญชีถูกระงับการใช้งาน)
- **สาเหตุ**: คอลัมน์ `is_active` ของผู้ใช้ในตาราง `users` ถูกตั้งเป็น `false`
- **วิธีแก้ไข**: ให้ผู้ดูแลระบบอัปเดตเป็น `true` ผ่าน SQL หรือระบบหลังบ้าน
