# 06-create-project.md — การสร้างโครงการ (Project Management)

## วัตถุประสงค์
เอกสารฉบับนี้อธิบายขั้นตอนการสร้างและจัดการ **โฟลเดอร์โครงการ (Project Folders)** ซึ่งใช้เป็นโครงสร้างระดับบนสุดในการจัดกลุ่มพื้นที่รับผิดชอบ (Managed Areas) และรอบการบินสำรวจทางอากาศ (Drone Surveys) เพื่อความสะดวกในการติดตามงาน การจัดสรรงบประมาณ และการควบคุมสิทธิ์การเข้าถึง

---

## สิ่งที่ต้องเตรียม
- สิทธิ์ผู้ใช้งานระดับ `admin` หรือ `project_manager`
- ข้อมูลชื่อโครงการและวัตถุประสงค์การติดตามงาน

---

## สิทธิ์ที่เกี่ยวข้อง (Permissions)
- **สร้าง/แก้ไขโครงการ**: `admin`, `project_manager`
- **ดูรายการโครงการ**: ทุกบทบาท (`admin`, `project_manager`, `analyst`, `viewer`)

---

## ขั้นตอนการทำงานทีละข้อ (Step-by-Step Instructions)

### ขั้นตอนที่ 1: เข้าสู่หน้าจัดการโครงการ
1. คลิกที่เมนู **"โครงการ"** บนแถบนำทางด้านบน (Navbar) หรือเข้า URL: `http://localhost:3000/projects`
2. ระบบจะโหลดข้อมูลโครงการทั้งหมดผ่าน API `GET /api/v1/projects`
3. หากยังไม่มีโครงการในระบบ หน้าจอจะแสดงสถานะว่าง (Empty State) พร้อมปุ่มสร้างโครงการแรก

### ขั้นตอนที่ 2: เปิดหน้าต่างสร้างโครงการใหม่
1. คลิกที่ปุ่ม **"+ สร้างโครงการใหม่ (New Project)"** ที่มุมบนขวา
2. หน้าต่างโมดัล (Modal Window) สำหรับกรอกข้อมูลโครงการจะปรากฏขึ้น

### ขั้นตอนที่ 3: กรอกข้อมูลโครงการ
กรอกรายละเอียดในแบบฟอร์ม:
- **ชื่อโครงการ (Project Name) \***: ระบุชื่อโครงการให้ชัดเจน เช่น:
  ```text
  โครงการติดตามงานปรับพื้นที่และก่อสร้างทางวิ่งสำรอง (Suvarnabhumi Runway Expansion)
  ```
- **รายละเอียดและวัตถุประสงค์ (Description)**: ระบุขอบเขตงาน เช่น:
  ```text
  การติดตามงานขุดลอกดิน ถมดินคันทาง และตรวจสอบความก้าวหน้ารายสัปดาห์ด้วยโดรนสำรวจความละเอียดสูง
  ```

### ขั้นตอนที่ 4: บันทึกโครงการ
1. คลิกปุ่ม **"บันทึกโครงการ (Save Project)"**
2. ระบบจะส่งข้อมูลแบบ JSON ไปยัง API `POST /api/v1/projects`
3. ระบบจะบันทึกประวัติกิจกรรมลงในตาราง Audit Log
4. หน้าต่างจะปิดลง และการ์ดโครงการใหม่จะปรากฏบนหน้าจอทันที

---

## ตัวอย่างคำสั่งสร้างโครงการผ่าน REST API (cURL Command)

สำหรับผู้ที่ต้องการเชื่อมต่อแบบอัตโนมัติหรือใช้งานผ่าน Script:

```bash
curl -X POST http://localhost:4000/api/v1/projects \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <YOUR_ACCESS_TOKEN>" \
  -d '{
    "name": "โครงการติดตามงานขุดถมพื้นที่พัฒนาเขตเศรษฐกิจพิเศษ",
    "description": "สำรวจความเปลี่ยนแปลงทางกายภาพและปริมาตรงานดินรอบเดือน"
  }'
```

**ผลลัพธ์ที่ได้รับ (HTTP 201 Created):**
```json
{
  "success": true,
  "data": {
    "id": "e4b1c8a0-2f34-4b56-8a7c-9d0e1f2a3b4c",
    "name": "โครงการติดตามงานขุดถมพื้นที่พัฒนาเขตเศรษฐกิจพิเศษ",
    "description": "สำรวจความเปลี่ยนแปลงทางกายภาพและปริมาตรงานดินรอบเดือน",
    "organizationId": "99c825b0-47d9-4b66-9d8d-d158ecab585a",
    "createdAt": "2026-10-26T04:20:00.000Z"
  },
  "message": "สร้างโครงการใหม่สำเร็จ"
}
```

---

## ผลลัพธ์และสิ่งที่ควรเห็นบนหน้าจอ (Expected Results)
- การ์ดโครงการใหม่จะแสดงรหัสอ้างอิงอัตโนมัติ เช่น `PROJ-E4B1C8A0`
- มีป้ายสถานะ `กำลังดำเนินการ`
- แสดงจำนวนแปลงพื้นที่ในโครงการ (เริ่มต้น 0 แปลง)
- เมนูเลือกโครงการบน Navbar ด้านบน (Project Selector) จะปรากฏชื่อโครงการนี้ให้สามารถเลือกสลับบริบทได้

---

## ข้อผิดพลาดที่พบบ่อยและวิธีแก้ไข

### ข้อผิดพลาด: `FORBIDDEN` (ไม่มีสิทธิ์ดำเนินการ)
- **สาเหตุ**: ผู้ใช้งานเข้าสู่ระบบด้วยสิทธิ์ `analyst` หรือ `viewer` ซึ่งไม่มีสิทธิ์สร้างโครงการ
- **วิธีแก้ไข**: แจ้งผู้ดูแลระบบ (`admin`) หรือเข้าสู่ระบบด้วยบัญชี `pm@geomonitor.local`

### ข้อผิดพลาด: ชื่อโครงการว่างเปล่า
- **สาเหตุ**: ช่อง "ชื่อโครงการ" เป็นฟิลด์บังคับตาม Zod Schema
- **วิธีแก้ไข**: ระบุชื่อโครงการอย่างน้อย 3 ตัวอักษร
