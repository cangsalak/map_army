# 07-create-managed-area.md — การสร้างพื้นที่รับผิดชอบ (Managed Areas)

## วัตถุประสงค์
เอกสารฉบับนี้อธิบายขั้นตอนการกำหนด **พื้นที่รับผิดชอบ (Managed Area)** และการบันทึกรูปแปลงรูปหลายเหลี่ยม (Polygon Boundary) ลงในฐานข้อมูล PostGIS เพื่อใช้เป็นขอบเขตอ้างอิงในการซ้อนทับภาพถ่ายโดรน การคำนวณเนื้อที่ และการตัดกรอบพื้นที่การเปลี่ยนแปลง

---

## สิ่งที่ต้องเตรียม
- สิทธิ์ผู้ใช้งานระดับ `admin` หรือ `project_manager`
- รหัสโครงการ (Project ID) ที่สร้างจากขั้นตอนก่อนหน้า (ทางเลือก)
- ชุดพิกัดภูมิศาสตร์ตามมาตรฐาน **WGS84 (EPSG:4326)** ในรูปแบบ **ลองจิจูด, ละติจูด (Longitude, Latitude)**

---

## ข้อกำหนดของรูปแปลง PostGIS (Spatial Geometry Requirements)

1. **ระบบพิกัดอ้างอิง (Coordinate Reference System - CRS)**:
   - ต้องเป็นพิกัดทางภูมิศาสตร์ WGS84 (EPSG:4326) ทศนิยม 4–6 ตำแหน่ง
2. **ลำดับพิกัด (Coordinate Order)**:
   - ต้องระบุ **Longitude (ค่า X ประมาณ 97° ถึง 106° สำหรับประเทศไทย)** นำหน้า **Latitude (ค่า Y ประมาณ 5° ถึง 21°)**
   - คั่นระหว่าง Longitude และ Latitude ด้วยเครื่องหมายจุลภาค (`,`)
3. **การปิดขอบเขตรูปแปลง (Closed Linear Ring)**:
   - จุดเริ่มต้น (จุดที่ 1) และจุดสุดท้าย (จุดที่ N) **ต้องเป็นพิกัดตัวเลขเดียวกัน** เพื่อให้ได้รูปปิดทางเรขาคณิต (Closed Ring)
   - ต้องมีจุดยอด (Vertices) อย่างน้อย 4 จุด (รูปสามเหลี่ยมที่ปิดหัวท้าย) หรือ 5 จุดขึ้นไปสำหรับรูปสี่เหลี่ยม

---

## ตัวอย่างชุดพิกัดที่ถูกต้อง (Valid Coordinates Example)

### ตัวอย่าง: แปลงพื้นที่สี่เหลี่ยมผืนผ้า (ขนาดประมาณ 2.2 x 2.2 กิโลเมตร)
```text
100.5000, 13.7500
100.5200, 13.7500
100.5200, 13.7700
100.5000, 13.7700
100.5000, 13.7500
```

## ขั้นตอนการสร้างพื้นที่ผ่านหน้าเว็บแอปพลิเคชัน

### วิธีที่ 1: ผ่านหน้าจัดการพื้นที่ (`/areas`)
1. เข้าไปที่เมนู **"พื้นที่ดูแล"** บน Navbar หรือ URL: `http://localhost:3000/areas`
2. คลิกปุ่ม **"+ กำหนดพื้นที่ใหม่ (Add New Area)"**
3. หน้าต่างโมดัลจะเปิดขึ้น กรอกข้อมูล:
   - **เลือกโครงการที่สังกัด (Project)**: เลือกโครงการที่ต้องการจัดกลุ่ม
   - **ชื่อพื้นที่ในการดูแล (Area Name) \***: เช่น `พื้นที่ก่อสร้างอาคารเทียบเครื่องบินรอง (Concourse Extension Zone)`
   - **คำอธิบายและวัตถุประสงค์ (Description)**: เช่น `พื้นที่ตรวจติดตามระดับดินและงานฐานราก`
   - **พิกัดขอบเขต (Polygon Coordinates - Lon, Lat ต่อบรรทัด) \***: วางชุดพิกัด 5 บรรทัดตามตัวอย่างข้างต้น
4. คลิกปุ่ม **"บันทึกและคำนวณพื้นที่ (Save & Compute)"**

### วิธีที่ 2: ผ่านศูนย์บัญชาการแผนที่ 3 มิติ (`/`)
1. ที่หน้าหลักศูนย์บัญชาการแผนที่ หากระบบยังไม่มีพื้นที่ จะมีแผงสถานะขึ้นตรงกลาง
2. คลิกปุ่ม **"+ สร้างพื้นที่ดูแลใหม่ (Create Area)"**
3. กรอกชื่อ รายละเอียด และพิกัดรูปแปลง แล้วกดบันทึก

---

## การคำนวณเนื้อที่อัตโนมัติด้วย PostGIS (Spatial Calculation Engine)

เมื่อส่งข้อมูลบันทึก Backend API จะแปลง GeoJSON เป็น PostGIS Geometry และใช้ฟังก์ชันเชิงพื้นที่แปลงเส้นโครงแผนที่ไปยัง **UTM Zone 47N (EPSG:32647)** เพื่อคำนวณขนาดเนื้อที่จริงบนระนาบผิวโลก:

$$\text{area\_sqm} = \text{ST\_Area}(\text{ST\_Transform}(\text{boundary}, 32647))$$

ระบบจะแปลงค่าพื้นที่เป็นหน่วยไทยให้อัตโนมัติ:
- **ไร่-งาน-ตารางวา**: คำนวณตามอัตราส่วน 1 ไร่ = 1,600 ตร.ม., 1 งาน = 400 ตร.ม., 1 ตารางวา = 4 ตร.ม.
- **ตารางเมตร (m²)**: แสดงผลในแผงข้อมูลและรายงาน

## ตัวอย่างคำสั่งสร้างพื้นที่ผ่าน REST API (cURL)

```bash
curl -X POST http://localhost:4000/api/v1/areas \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <YOUR_ACCESS_TOKEN>" \
  -d '{
    "name": "พื้นที่สำรวจลานจอดอากาศยาน โซน A",
    "description": "ติดตามการขุดลอกดินและการถมดินลูกรังปรับระดับ",
    "boundary": {
      "type": "Polygon",
      "coordinates": [
        [
          [100.5000, 13.7500],
          [100.5200, 13.7500],
          [100.5200, 13.7700],
          [100.5000, 13.7700],
          [100.5000, 13.7500]
        ]
      ]
    },
    "status": "active"
  }'
```

```json
    "createdAt": "2026-10-26T04:22:00.000Z"
  },
  "message": "สร้างพื้นที่และคำนวณขนาดเนื้อที่สำเร็จ"

```

## ผลลัพธ์และสิ่งที่ควรเห็นบนแผนที่ 3 มิติ (Expected Results)
1. ขอบเขตพื้นที่สีฟ้าไซแอนเรืองแสง (Cyan Glow Polygon Boundary) จะถูกวาดลงบน CesiumJS Virtual Globe ทันที
2. แผงควบคุมกล้องจะบินไปยังจุดกึ่งกลางของพื้นที่ (Fly To Bounding Sphere) อัตโนมัติ
3. เมนูด้านซ้าย (Left Sidebar) ในแท็บ "พื้นที่" จะมีรายการพื้นที่นี้เพิ่มขึ้น พร้อมแสดงเนื้อที่คำนวณและสถานะ
4. แผง Inspector ด้านขวาจะเริ่มแสดงสถิติและข้อมูลทางเทคนิคของพื้นที่

## ข้อผิดพลาดที่พบบ่อยและวิธีแก้ไข

### ข้อผิดพลาด: `INVALID_POLYGON_UNCLOSED` (จุดเริ่มต้นและจุดสุดท้ายไม่ตรงกัน)
- **สาเหตุ**: บรรทัดสุดท้ายของพิกัดมีค่าไม่เท่ากับบรรทัดแรก
- **วิธีแก้ไข**: คัดลอกพิกัดของบรรทัดที่ 1 มาวางเป็นบรรทัดสุดท้ายอีกครั้ง

### ข้อผิดพลาด: พิกัดกระโดดไปตกที่ทวีปแอฟริกาหรือมหาสมุทร
- **สาเหตุ**: ใส่พิกัดสลับกันระหว่าง Latitude และ Longitude (เช่น ใส่ `13.7500, 100.5000`)
- **วิธีแก้ไข**: ในระบบ GIS มาตรฐาน สลับให้ค่า Longitude (~100.x) ขึ้นก่อน Latitude (~13.x)
