# 08-upload-drone-images.md — การนำเข้าภาพถ่ายโดรนและลงทะเบียนรอบบินสำรวจ

## วัตถุประสงค์
เอกสารฉบับนี้อธิบายขั้นตอนการลงทะเบียน **รอบการบินสำรวจทางอากาศ (Drone Survey Record)** พร้อมพารามิเตอร์การบินจริง และการนำส่งไฟล์ผลลัพธ์การรังวัด (Deliverable Assets) เช่น ภาพถ่ายออร์โธโมเสก (Orthomosaic) และแบบจำลองระดับความสูงพื้นผิว (DSM) เข้าสู่พื้นที่จัดเก็บ MinIO S3 ของระบบ

---

## สิ่งที่ต้องเตรียม
- สิทธิ์ผู้ใช้งานระดับ `admin`, `project_manager` หรือ `analyst`
- พื้นที่รับผิดชอบ (Managed Area) ที่สร้างไว้แล้ว
- ข้อมูลพารามิเตอร์การบินจริง (Log การบินจากรีโมตคอนโทรลเลอร์หรือซอฟต์แวร์วางแผนการบิน เช่น DJI Pilot 2)
- ไฟล์ภาพผลลัพธ์ที่ผ่านการแปลงเป็นพิกัดทางภูมิศาสตร์ (Georeferenced GeoTIFF / COG) หรือชุดภาพดิบ

---

## ข้อมูลพารามิเตอร์การบินสำรวจ (Flight Metadata Specifications)

ในการลงทะเบียนรอบบินสำรวจ ระบบต้องการข้อมูลทางเทคนิคเพื่อใช้คำนวณความคลาดเคลื่อนและความละเอียดของข้อมูล:

| พารามิเตอร์ | ตัวอย่างค่าที่ถูกต้อง | คำอธิบายเชิงเทคนิค |
|---|---|---|
| **รหัสรอบบิน (Survey Code) \*** | `SRV-ZONEA-2026-01` | รหัสอ้างอิงเฉพาะของรอบบินสำรวจ (ห้ามซ้ำในพื้นที่เดียวกัน) |
| **วันที่และเวลาทำการบิน (Survey Date) \*** | `2026-01-15` | วันที่ขึ้นบินสำรวจจริง |
| **รุ่นของอากาศยานไร้คนขับ (Drone Model)** | `DJI Matrice 350 RTK` | โมเดลของโดรนที่ใช้สำรวจ (แนะนำรุ่นที่รองรับ RTK/PPK) |
| **รุ่นของเซนเซอร์กล้อง (Sensor Type)** | `Zenmuse P1 45MP Full-Frame` | เซนเซอร์บันทึกภาพเพื่อใช้อ้างอิง Focal Length และ Sensor Size |
| **ความสูงการบินเฉลี่ย (Flight Altitude M)** | `120` | ความสูงเหนือพื้นดิน (AGL) หน่วยเป็นเมตร |
| **ความละเอียดภาพภาคพื้นดิน (GSD cm/px)** | `2.5` | Ground Sample Distance หน่วยเป็นเซนติเมตรต่อจุดภาพ |
| **ระบบพิกัดราบ (Horizontal CRS)** | `EPSG:4326` หรือ `EPSG:32647` | ระบบพิกัดทางราบ (WGS84 หรือ UTM Zone 47N) |
| **ระบบพิกัดดิ่ง (Vertical CRS)** | `EGM96` หรือ `WGS84 Ellipsoid` | แบบจำลองจีออยด์สำหรับอ้างอิงระดับความสูงเฉลี่ยน้ำทะเลปานกลาง |

---

## ประเภทของไฟล์ผลลัพธ์ที่ระบบรองรับ (Supported Asset Types)

ระบบจัดเก็บไฟล์ลงใน MinIO S3 Bucket `geomonitor-assets` โดยรองรับประเภทไฟล์ดังนี้:

1. `orthomosaic`: ภาพถ่ายดัดแก้ทางราบรวมเป็นผืนเดียว (GeoTIFF / COG `.tif`)
2. `dsm`: แบบจำลองระดับความสูงเชิงเลขของพื้นผิว (Digital Surface Model `.tif`)
3. `dtm`: แบบจำลองระดับความสูงเชิงเลขของภูมิประเทศปราศจากสิ่งปกคลุม (Digital Terrain Model `.tif`)
4. `point_cloud`: กลุ่มจุดความหนาแน่นสูง (LAS / LAZ `.laz`)
5. `mesh_3d`: แบบจำลองพื้นผิว 3 มิติพร้อมผิวสัมผัส (Cesium 3D Tiles / OBJ / GLB)
6. `raw_images_archive`: ไฟล์บีบอัดชุดภาพดิบจากกล้องโดรน (.zip)

---

## ขั้นตอนการลงทะเบียนรอบบินผ่านหน้าเว็บ (`/surveys`)

1. คลิกเมนู **"ข้อมูลโดรน"** บน Navbar หรือเข้าไปที่ URL: `http://localhost:3000/surveys`
2. ที่แถบด้านบน ให้เลือก **พื้นที่เป้าหมาย (Target Area)** ที่ต้องการบันทึกข้อมูล
3. คลิกปุ่ม **"+ ลงทะเบียนรอบบินใหม่ (Register Survey)"**
4. หน้าต่างโมดัลจะเปิดขึ้น กรอกข้อมูลพารามิเตอร์การบิน:
   - **รหัสรอบบินสำรวจ**: เช่น `SRV-2026-01-BASE`
   - **วันที่สำรวจ**: เลือกวันที่จากปฏิทิน
   - **รุ่นโดรนและเซนเซอร์**: ระบุรุ่นโดรนและกล้อง
   - **ความสูงบิน (เมตร) และ GSD (ซม.)**: ระบุตัวเลข
5. คลิกปุ่ม **"บันทึกข้อมูลรอบบิน (Save Survey)"**

---

## ขั้นตอนการนำเข้าไฟล์ภาพผลลัพธ์ (Asset Deliverables Upload)

เมื่อลงทะเบียนรอบบินสำเร็จ รายการรอบบินจะปรากฏในตาราง:
1. คลิกเลือกแถวของรอบบินที่ต้องการ
2. ในแผงรายละเอียดด้านล่าง คลิกปุ่ม **"+ อัปโหลดไฟล์ผลลัพธ์ (Upload Deliverable)"**
3. เลือก **ประเภทไฟล์ (Asset Type)** เช่น `ภาพถ่ายออร์โธโมเสก (Orthomosaic)` หรือ `แบบจำลองความสูง (DSM)`
4. ระบุชื่อไฟล์ (เช่น `ortho_zonea_jan2026.tif`) และขนาดไฟล์ (MB)
5. ติ๊กเลือก **"กำหนดเป็นเลเยอร์หลัก (Set as Primary Layer)"** หากเป็นภาพหลักของรอบบินนั้น
6. คลิกปุ่ม **"บันทึกไฟล์ผลลัพธ์ (Register Asset)"**

---

## ตัวอย่างคำสั่งลงทะเบียนผ่าน REST API (cURL)

### 1. ลงทะเบียนรอบบิน (Create Survey):
```bash
curl -X POST http://localhost:4000/api/v1/areas/<AREA_ID>/surveys \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <YOUR_ACCESS_TOKEN>" \
  -d '{
    "surveyCode": "SRV-ZONEA-2026-01",
    "surveyDate": "2026-01-15T09:00:00.000Z",
    "droneModel": "DJI Matrice 350 RTK",
    "sensorType": "Zenmuse P1 45MP Full-Frame",
    "flightAltitudeM": 120,
    "groundSampleDistanceCm": 2.5,
    "crsHorizontal": "EPSG:4326",
    "crsVertical": "EGM96"
  }'
```

### 2. ลงทะเบียนไฟล์ Asset (Register Deliverable Asset):
```bash
curl -X POST http://localhost:4000/api/v1/surveys/<SURVEY_ID>/assets \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <YOUR_ACCESS_TOKEN>" \
  -d '{
    "assetType": "orthomosaic",
    "fileName": "ortho_jan2026_wgs84.tif",
    "fileSizeBytes": 524288000,
    "mimeType": "image/tiff",
    "checksumSha256": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
    "resolutionMPerPx": 0.025,
    "isPrimary": true
  }'
```

## ผลลัพธ์และวิธีตรวจสอบความสำเร็จ (Verification)
1. ในหน้า `/surveys` รายการรอบบินจะแสดงจำนวนไฟล์ผลลัพธ์ (Assets Count) อัปเดตทันที
2. ที่หน้าศูนย์บัญชาการ 3D (`/`) แถบไทม์ไลน์ด้านล่าง (Survey Timeline) จะแสดงปุ่มรอบบินตามวันที่ที่ลงทะเบียนไว้
3. สามารถคลิกเลือกรอบบินเพื่อเปิดเลเยอร์ภาพ Orthomosaic บนลูกโลก CesiumJS ได้

---

## ข้อผิดพลาดที่พบบ่อยและวิธีแก้ไข

### ข้อผิดพลาด: `DUPLICATE_SURVEY_CODE`
- **สาเหตุ**: มีการใช้รหัสรอบบินสำรวจซ้ำกับข้อมูลที่มีอยู่เดิมในพื้นที่เดียวกัน
- **วิธีแก้ไข**: ตรวจสอบและตั้งชื่อรหัสรอบบินให้มีรหัสวันที่กำกับ เช่น เพิ่มเดือนหรือปี

### ข้อผิดพลาด: ค่า GSD สูงเกินเกณฑ์มาตรฐาน
- **สาเหตุ**: ความสูงบินสูงเกินไป ทำให้ความละเอียดของภาพไม่เพียงพอต่อการวิเคราะห์ดินขุด-ถม (แนะนำ GSD ไม่เกิน 3–5 ซม./พิกเซล สำหรับงานคำนวณปริมาตรดิน)
- **วิธีแก้ไข**: ปรับแผนการบินโดยลดระดับความสูงในการบินสำรวจครั้งต่อไป
