# 11-manage-surveys.md — การจัดการประวัติการบินสำรวจและเลือกช่วงเวลาเปรียบเทียบ

## วัตถุประสงค์
เอกสารฉบับนี้อธิบายการจัดการประวัติการบินสำรวจทางอากาศ (Historical Survey Timeline) การคัดเลือกรอบบินอ้างอิง (Baseline Survey) และรอบบินเปรียบเทียบ (Comparison Survey) รวมถึงการเปิดใช้งาน **โหมดสไลด์ผ่าภาพก่อน-หลัง (Before/After Swipe Comparison)**

---

## สิ่งที่ต้องเตรียม
- พื้นที่รับผิดชอบที่มีรอบบินสำรวจอย่างน้อย 2 รอบบิน (เช่น รอบบินเดือนมกราคม และรอบบินเดือนมีนาคม)
- ไฟล์ภาพออร์โธโมเสกที่ลงทะเบียนสมบูรณ์แล้วของทั้งสองรอบบิน

---

## การทำความเข้าใจแนวคิด Baseline และ Comparison Survey

ในการวิเคราะห์ความเปลี่ยนแปลงทางภูมิศาสตร์ ต้องมีจุดเปรียบเทียบ 2 ช่วงเวลาเสมอ:
1. **รอบบินอ้างอิง (Baseline Survey - $T_1$)**:
   - คือสภาพพื้นที่ก่อนเกิดการเปลี่ยนแปลง เช่น สภาพพื้นที่ตามแนวสัญญาก่อนเริ่มงานขุด หรือภาพถ่ายต้นงวด
   - ในระบบจะมีป้ายกำกับสีน้ำเงินเข้ม: `[ อ้างอิง / Base ]`
2. **รอบบินเปรียบเทียบ (Comparison Survey - $T_2$)**:
   - คือสภาพพื้นที่ปัจจุบันที่มีการดำเนินงานแล้ว หรือภาพถ่ายงวดงานล่าสุดที่ต้องการตรวจรับ
   - ในระบบจะมีป้ายกำกับสีเขียวมรกต: `[ เปรียบเทียบ / Cmp ]`

---

## ขั้นตอนการเลือกรอบบินบนแถบไทม์ไลน์ (Survey Timeline Controls)

ที่บริเวณด้านล่างของหน้าจอศูนย์บัญชาการแผนที่ 3 มิติ จะมีแถบ **Survey Timeline**:

1. **เลือกพื้นที่เป้าหมาย**: เลือกรอบแปลงที่ต้องการจากแถบ Navbar หรือ Left Sidebar
2. **ดูรายการรอบบิน**: แถบไทม์ไลน์จะแสดงการ์ดรอบบินเรียงตามลำดับเวลาจากอดีตมาปัจจุบัน
3. **กำหนดรอบบินอ้างอิง ($T_1$)**:
   - คลิกที่ปุ่ม **"ตั้งเป็นรอบอ้างอิง (Set Baseline)"** บนการ์ดรอบบินที่ต้องการ
   - การ์ดนั้นจะขึ้นกรอบสีฟ้าไซแอนเรืองแสง
4. **กำหนดรอบบินเปรียบเทียบ ($T_2$)**:
   - คลิกที่ปุ่ม **"ตั้งเป็นรอบเปรียบเทียบ (Set Comparison)"** บนการ์ดรอบบินล่าสุด
   - การ์ดนั้นจะขึ้นกรอบสีเขียวมรกต

---

## การใช้งานโหมดสไลด์ผ่าภาพเปรียบเทียบ (Before/After Swipe Mode)

เมื่อเลือกรอบบินอ้างอิงและเปรียบเทียบครบทั้ง 2 ช่วงเวลาแล้ว:

1. คลิกปุ่ม **"เปรียบเทียบภาพ (Swipe Mode)"** บนแถบ Navbar ด้านบน หรือบนแถบ Timeline
2. หน้าจอแผนที่จะปรากฏ **เส้นแบ่งภาพแนวดิ่งสีฟ้าไซแอน (Vertical Split Line)** ผ่ากลางหน้าจอ
3. **การทำงานของสองฝั่ง**:
   - **ฝั่งซ้ายของเส้น**: แสดงภาพถ่ายทางอากาศของรอบบินอ้างอิง ($T_1$)
   - **ฝั่งขวาของเส้น**: แสดงภาพถ่ายทางอากาศของรอบบินเปรียบเทียบ ($T_2$)
4. **การเลื่อนปรับตำแหน่งเส้นแบ่งภาพ**:
   - สามารถใช้เมาส์ลากเส้นแบ่งภาพไปทางซ้ายหรือขวาได้โดยตรง
   - หรือปรับแถบสไลเดอร์เปอร์เซ็นต์ (0%–100%) บนแถบไทม์ไลน์ด้านล่าง
5. เครื่องมือนี้ช่วยให้นักวิเคราะห์เห็นความเปลี่ยนแปลงของแนวคันดิน สิ่งปลูกสร้าง หรือการบุกรุกพื้นที่ได้อย่างชัดเจนในระดับจุดภาพต่อจุดภาพ

---

## การตรวจสอบรายละเอียดรอบบินในหน้า `/surveys`

หากต้องการตรวจสอบคุณลักษณะทางเทคนิคของรอบบินอย่างละเอียด:
1. ไปที่เมนู **"ข้อมูลโดรน"** (`/surveys`)
2. คลิกเลือกรอบบินในตาราง
3. แผงข้อมูลจะแสดง:
   - **รหัสรอบบิน**: เช่น `SRV-ZONEA-2026-02`
   - **วันที่และเวลาบิน**: เช่น `15 มีนาคม 2026, 10:30 น.`
   - **ความสูงบินจริงและ GSD**: เช่น ความสูง 120 ม., GSD 2.5 ซม./พิกเซล
   - **ระบบพิกัดอ้างอิง**: Horizontal EPSG:4326 / Vertical EGM96
   - **รายการไฟล์ Assets ที่ผูกอยู่**: แสดงชื่อไฟล์ ขนาดไฟล์ และค่า Checksum SHA-256

## ตัวอย่างคำสั่งดึงข้อมูลประวัติรอบบินผ่าน REST API

```bash
curl -s http://localhost:4000/api/v1/areas/<AREA_ID>/surveys \
  -H "Authorization: Bearer <YOUR_ACCESS_TOKEN>" | jq .
```

## ข้อผิดพลาดที่พบบ่อยและวิธีแก้ไข

### ข้อผิดพลาด: เลือกรอบบินเดียวกันทั้ง Baseline และ Comparison
- **สาเหตุ**: ผู้ใช้งานเลือกรอบบินเดียวกันสำหรับ $T_1$ และ $T_2$
- **วิธีแก้ไข**: ปุ่ม "เปรียบเทียบการเปลี่ยนแปลง (Analyze Changes)" จะถูกระงับการคลิก (Disabled) อัตโนมัติ ให้เลือกรอบบินที่ต่างเวลากันอย่างน้อย 2 รอบ

---

## ขั้นตอนถัดไป
เมื่อเลือกรอบบินสำรวจสองช่วงเวลาที่ต้องการเปรียบเทียบเรียบร้อยแล้ว ให้เริ่มกระบวนการคำนวณและตรวจจับการเปลี่ยนแปลงใน [12-change-detection.md](12-change-detection.md)
