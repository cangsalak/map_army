# 10-view-3d-map.md — การดูแผนที่ 3 มิติและการควบคุมด้วย CesiumJS

## วัตถุประสงค์
เอกสารฉบับนี้อธิบายการใช้งานเครื่องมือใน **ศูนย์บัญชาการแผนที่ 3 มิติ (3D GIS Command Center Canvas)** ซึ่งขับเคลื่อนด้วยเอนจิน **CesiumJS** การควบคุมมุมกล้อง การซ้อนทับชั้นข้อมูลภาพ การปรับความโปร่งแสง และการใช้งานเครื่องมือวัดระยะและพื้นที่

---

## สิ่งที่ต้องเตรียม
- อุปกรณ์คอมพิวเตอร์ลูกข่ายที่เปิดใช้งาน Hardware Acceleration ในเว็บบราวเซอร์
- มีพื้นที่รับผิดชอบและข้อมูลรอบบินสำรวจในระบบแล้ว

---

## การควบคุมมุมมองแผนที่ 3 มิติด้วยเมาส์ (Mouse Navigation Controls)

| การกระทำด้วยเมาส์ | การทำงานบนแผนที่ CesiumJS |
|---|---|
| **คลิกซ้ายค้าง + ลาก (Left Click + Drag)** | เลื่อนแผนที่ไปในทิศทางต่างๆ (Pan / Orbit) |
| **หมุนลูกกลิ้งเมาส์ (Mouse Scroll Wheel)** | ซูมเข้าและซูมออก (Zoom In / Zoom Out) |
| **คลิกขวาค้าง + ลากขึ้น-ลง (Right Click + Drag)** | ซูมเข้า-ออกอย่างละเอียดและนุ่มนวล |
| **คลิกล้อกลางค้าง + ลาก (Middle Click + Drag)** | ปรับมุมก้ม-เงยของกล้อง (Tilt / Pitch) และหมุนทิศเหนือ (Heading) |
| **กดปุ่ม `Ctrl` ค้าง + คลิกซ้ายลาก** | หมุนมุมมองรอบจุดศูนย์กลางแบบ 3 มิติ (Free 3D Look Around) |

---

## แถบเครื่องมือควบคุมแผนที่ (Map Tools Toolbar — มุมบนขวา)

ที่มุมบนขวาของจอแผนที่มีชุดไอคอนควบคุมการทำงาน:

1. **ขยายมุมมอง (Zoom In - รูปแว่นขยายบวก)**: เพิ่มระดับการซูม 35%
2. **ย่อมุมมอง (Zoom Out - รูปแว่นขยายลบ)**: ถอยระดับการซูมออก 45%
3. **รีเซ็ตมุมมองหลัก (Reset Camera - รูปเป้าเล็ง)**: สั่งให้กล้องบินกลับมายังตำแหน่งพิกัดศูนย์กลางของพื้นที่ที่ระดับความสูง 4,500 เมตร มุมเอียง 50 องศา
4. **วัดระยะทางแนวราบ (Distance Measurement - รูปไม้บรรทัด)**:
   - คลิกไอคอนไม้บรรทัดเพื่อเริ่มโหมดวัดระยะ
   - คลิกจุดเริ่มต้นและจุดปลายทางบนแผนที่
   - ระบบจะคำนวณระยะทางจริง (หน่วยเป็นเมตร หรือกิโลเมตร) พร้อมแสดงป้ายข้อความสรุป
5. **วัดพื้นที่รูปหลายเหลี่ยม (Area Measurement - รูปทรงหลายเหลี่ยม)**:
   - คลิกไอคอนรูปทรงหลายเหลี่ยม
   - คลิกจุดยอด (Vertices) รอบบริเวณที่ต้องการวัดตั้งแต่ 3 จุดขึ้นไป
   - ระบบจะคำนวณขนาดเนื้อที่ตามเส้นโครงแผนที่ PostGIS พร้อมแสดงผลเป็น ตารางเมตร (m²) และ ไร่-งาน-ตารางวา
6. **ล้างค่าการวัด (Clear Measurements - รูปถังขยะ)**: ล้างเส้นและป้ายการวัดระยะออกจากหน้าจอ

## แถบแสดงพิกัดและคุณลักษณะเชิงพื้นที่แบบเรียลไทม์ (Bottom-Left Coordinate HUD)

ที่มุมล่างซ้ายของแผนที่ 3D มีแผง HUD แสดงข้อมูลพิกัดของตำแหน่งเคอร์เซอร์เมาส์แบบเรียลไทม์:
- **LAT**: ค่าละติจูดทศนิยม 5 ตำแหน่ง (เช่น `13.75012° N`)
- **LON**: ค่าลองจิจูดทศนิยม 5 ตำแหน่ง (เช่น `100.51034° E`)
- **ELEV**: ระดับความสูงจากระดับน้ำทะเลปานกลาง (Elevation) คำนวณจากแบบจำลอง DSM (เช่น `14.5 ม.`)
- **CRS**: ระบบพิกัดอ้างอิงของชั้นข้อมูล (`EPSG:4326 WGS84`)

---

## การควบคุมการแสดงผลและปรับความโปร่งแสงของเลเยอร์ (Layer Opacity Control)

ที่แถบเมนูด้านซ้าย (Left Sidebar) คลิกเลือกแท็บ **"เลเยอร์ (Layers)"**:
1. **ภาพถ่ายออร์โธโมเสก (Orthomosaic)**:
   - ปรับแถบสไลเดอร์ความโปร่งแสงตั้งแต่ `0%` (โปร่งใส) ถึง `100%` (ทึบแสงสมบูรณ์)
   - ใช้ตรวจสอบความสอดคล้องกับภาพถ่ายดาวเทียมพื้นหลัง
2. **แบบจำลองความสูงพื้นผิว (DSM / Hillshade)**:
   - ปรับแถบสไลเดอร์ระดับสีเพื่อดูลักษณะความลาดชันและร่องรอยการขุดดิน
3. **แบบจำลอง 3 มิติ (3D Mesh / Photogrammetry Tiles)**:
   - ปรับการแสดงผลโมเดลสิ่งปลูกสร้าง คันดิน และกองวัสดุ

---

## คำอธิบายสัญลักษณ์สีบนแผนที่ (Change Detection Legend — มุมล่างขวา)

ที่มุมล่างขวาของแผนที่มีกล่องคำอธิบายสัญลักษณ์สีของรูปแปลงการเปลี่ยนแปลง:

- 🟥 **สีแดงกุหลาบ (Rose `#f43f5e`)**: บริเวณที่มีการ **ขุดดิน (Cut / Excavation)** ระดับพื้นดินลดลงจากรอบบินอ้างอิง ($\Delta Z < 0$)
- 🟩 **สีเขียวมรกต (Emerald `#10b981`)**: บริเวณที่มีการ **ถมดิน (Fill / Reclamation)** มีการนำดินมาพูนหรือก่อสร้างคันหิน ($\Delta Z > 0$)
- 🟦 **สีฟ้าไซแอน (Cyan `#06b6d4`)**: บริเวณ **สิ่งปลูกสร้างและโครงสร้างพื้นฐานใหม่ (New Structures)**
- 🟨 **สีเหลืองอำพัน (Amber `#f59e0b`)**: บริเวณ **การเปลี่ยนแปลงของพืชพรรณและแนวต้นไม้ (Vegetation Clearing)**

ผู้ใช้งานสามารถคลิกที่ปุ่มดวงตาหน้าแต่ละสัญลักษณ์เพื่อ **เปิด/ปิดการแสดงผลเลเยอร์** นั้นๆ ได้อย่างอิสระ

---

## ข้อผิดพลาดที่พบบ่อยและวิธีแก้ไข

### ข้อผิดพลาด: แผนที่ 3D ไม่โหลด จอดำ หรือขึ้นว่า `WebGL Not Supported`
- **สาเหตุ**: บราวเซอร์ไม่ได้เปิดใช้งาน Hardware Acceleration หรือไดรเวอร์การ์ดจอยังไม่รองรับ WebGL 2.0
- **วิธีแก้ไข**:
  1. ใน Google Chrome ไปที่ `chrome://settings/system` แล้วเปิด **"Use graphics acceleration when available"**
  2. เข้าไปที่ `chrome://flags` ค้นหา `WebGL 2.0 Compute` แล้วปรับเป็น Enabled
  3. รีสตาร์ตเว็บบราวเซอร์
